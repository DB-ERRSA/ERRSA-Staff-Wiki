# :material-store-outline: Tebex

Tebex is the storefront platform intended for Minecraft purchases and server-side package delivery.

---

## ERRSA Minecraft Use

Tebex is planned to provide the ERRSA Minecraft storefront where players can purchase supported packages such as the **VIP rank**.

The service is **not currently configured for player use**, but the Minecraft server is prepared for future integration.

When enabled, a Tebex purchase can trigger the server commands assigned to that package. Those commands are delivered to the Minecraft server hosted through Apex Hosting, allowing purchases such as a VIP package to be granted automatically.

---

## Access

[Open Tebex ↗](https://www.tebex.io/){ .md-button .md-button--primary }

Tebex management is limited to staff responsible for the store and its server integration.

---

## Core Areas

| Area | Used For |
| --- | --- |
| **Storefront** | The player-facing shop where available server packages are displayed. |
| **Packages** | Defining items such as VIP and the commands or rewards attached to them. |
| **Payments & Orders** | Reviewing completed purchases and transaction records once the store is active. |
| **Server Integration** | Delivering configured package commands to the Apex-hosted Minecraft server. |
