## What Is SkBee?

SkBee is a Skript add-on that provides modern Paper-compatible events, NBT support, particles, scoreboards, bounds, components, and other advanced scripting features.

## ERRSA's Use

ERRSA uses SkBee as part of the custom Skript stack, especially for bound/region-style event support used by portal and teleport workflows.

??? note "ERRSA Configuration"

    | Setting / Area | ERRSA Value | Purpose |
    |----------------|-------------|---------|
    | Debug | Disabled | Avoid verbose production logging |
    | Update checker | Enabled | Surface new releases |
    | Unsafe NBT operations | Disabled | Reduce risk from unsafe data manipulation |
    | Bound support | Enabled | Support region/bound-based scripted systems |
    | Particle / NBT / scoreboard / component modules | Enabled | Support active Skript features |
    | Virtual furnace | Disabled | Keep unused experimental functionality off |
    | Runtime errors / warnings | Visible | Keep script failures diagnosable |

    !!! warning "Skript dependency"
        SkBee expands Skript rather than replacing it. Test portal and region scripts after SkBee, Skript, or Paper updates.
