## What Is WorldGuard Extra Flags?

WorldGuard Extra Flags extends WorldGuard with additional region flags beyond the standard WorldGuard set.

## ERRSA's Use

ERRSA uses it when a protected region needs more specialized behavior than standard WorldGuard flags provide. Access follows the same high-impact region-management model as WorldGuard itself.
