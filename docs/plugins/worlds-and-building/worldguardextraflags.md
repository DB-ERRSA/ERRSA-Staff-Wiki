## What Is WorldGuardExtraFlags?

WorldGuard Extra Flags extends WorldGuard by adding additional region flags for more advanced control over gameplay behavior within protected areas.

## ERRSA's Use

ERRSA documents **WorldGuardExtraFlags** as part of the **Worlds And Building** plugin group on the Survival server.

---

??? note "Common Commands"

    | Command | Description | Who Can Use It |
    |---------|-------------|----------------|
    | `/rg flag <region> <flag> <value>` | apply extra flags to regions | Dev |
