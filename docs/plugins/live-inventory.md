# Live server inventory

This page is updated from a snapshot submitted **once each time Survival or Velocity starts**. The wiki does not poll the game servers. Snapshots can be older than currently installed files until the corresponding server restarts.

!!! warning "Permission coverage"
    Paper permissions below include metadata-declared permissions and permissions registered at startup. Dynamically checked but unregistered nodes may be missing. Velocity does not expose a complete plugin permission catalogue through its standard API. **These are not verified LuckPerms role grants.** Refer to [Staff permissions](staff-permissions.md) for the existing rank assignment reference.
