## What Is Vault?

Vault is an API bridge that gives plugins a common way to work with economy, permissions, and chat providers.

## ERRSA's Use

ERRSA uses Vault as an infrastructure dependency so plugins can interact consistently with systems such as EssentialsX economy and LuckPerms without directly depending on each implementation.
