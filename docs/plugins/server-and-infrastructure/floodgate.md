## What Is Floodgate?

Floodgate allows Bedrock Edition players to authenticate and join a Java Edition server through Geyser without requiring a Java account for the Bedrock connection.

## ERRSA's Use

ERRSA uses Floodgate as part of Bedrock support. After players connect, normal ERRSA initialization and permission systems handle their server access.
