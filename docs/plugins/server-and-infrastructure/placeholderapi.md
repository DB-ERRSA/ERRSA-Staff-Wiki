## What Is PlaceholderAPI?

PlaceholderAPI provides a shared placeholder system that lets plugins display dynamic values such as player information, ranks, and economy data.

## ERRSA's Use

ERRSA uses PlaceholderAPI to provide dynamic information to other plugins and interfaces. Installed expansions should stay limited to what the server actually needs.

??? note "ERRSA Configuration"

    | Setting / Area | ERRSA Value | Purpose |
    |----------------|-------------|---------|
    | Installed expansions | `luckperms`, `player`, `vault` | Supply rank, player, and economy placeholders |
    | Update checks | Enabled | Surface available updates |
    | eCloud | Enabled | Allow supported expansion downloads |
    | Debug | Disabled | Avoid unnecessary console output |

    !!! info "Expansion scope"
        Avoid installing unused expansions. Keep the expansion set limited to active ERRSA integrations.
