## What Is SilkSpawners v2?

SilkSpawners lets supported mob spawners be broken, collected, placed, and administratively changed under controlled conditions.

## ERRSA's Use

ERRSA uses SilkSpawners to allow controlled player movement of spawners while keeping administrative spawner creation and editing restricted to staff.

??? note "ERRSA Configuration"

    | Setting / Area | ERRSA Value | Purpose |
    |----------------|-------------|---------|
    | Locale | `en` | Use English plugin messages |
    | Valid spawner drop chance | `100%` | Always drop when valid break conditions are met |
    | Spawners destroyable | Enabled | Allow configured spawner breaking |
    | Pickaxe required | Enabled | Require a pickaxe for valid breaks |
    | Silk Touch required | Enabled | Require Silk Touch to obtain the spawner item |
    | Explosion drop chance | `0%` | Prevent explosions from yielding spawners |
    | Permission-based destroy/place/change | Enabled | Keep spawner actions permission-controlled |
    | Update checks | Enabled | Surface available plugin updates |
    | Update interval | `24h` | Check once per day |

    !!! info "Unchanged settings"
        Only intentional ERRSA configuration choices are listed here.
