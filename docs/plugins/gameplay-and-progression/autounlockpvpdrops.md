## What Is AutoUnlockPvPDrops?

AutoUnlockPvPDrops is a custom ERRSA plugin for server-specific handling of item drops created through PvP.

## ERRSA's Use

ERRSA uses AutoUnlockPvPDrops as part of the Survival server's custom PvP item-drop behavior. The implementation is maintained internally.
