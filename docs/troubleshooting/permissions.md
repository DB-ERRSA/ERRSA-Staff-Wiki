# Commands & permissions

If someone cannot use a command, ask **which command**, **which server/world**, and **what error appears**. Confirm their expected role before assuming a permissions bug.

Do not grant elevated permissions as a quick fix. Refer suspected permission changes to an authorized Admin, Developer, or Server Lead. See [Staff Permissions](../plugins/staff-permissions.md) and [LuckPerms](../plugins/permissions-and-moderation/luckperms.md).
