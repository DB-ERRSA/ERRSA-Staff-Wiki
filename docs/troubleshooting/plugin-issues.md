# Plugin & integration issues

Start by recording **what failed**, **where and when**, and **whether it affects one player or several**. Check existing staff reports before creating a duplicate.

Plugin, database, and automation changes must be handled by authorized staff. Do not restart services or modify live configurations as an unapproved experiment. See [Plugin documentation](../plugins/index.md) and [Staff Actions & Records](../documentation/logging-documentation.md).
