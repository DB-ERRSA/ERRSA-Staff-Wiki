# Admin Certification & Training Record

**Admin certification is required for all Admins.** A prospective Admin must complete it before promotion; a current Admin must complete it within the transition deadline set by the Server Lead. See [Staff Advancement & Governance §6.1.1](../../documentation/6-staff-advancement-and-governance.md#611-required-admin-certification){ data-preview }.

Complete this record after the [Admin Practical Assessment](assessment.md){ data-preview } and supervised exercises. It documents what was demonstrated and which duties are independently authorized. **Certification is not an automatic promotion:** the Server Lead makes the final certification and promotion decisions.

!!! important "Keep the record in approved staff storage"
    Make a copy of this template for each trainee and record the final result in the appropriate internal staff training record. Do not publish player information, evidence, or staff assessment notes on the public wiki.
