# Server Lead Assessment

Candidates complete this assessment as part of the [Server Lead selection process](../../documentation/6-staff-advancement-and-governance.md#64-server-lead-selection){ data-preview }. Passing an assessment does not replace the required election.

## 1. Staff Disagreement

An Admin and Developer disagree about an urgent live-server change. Explain how you would reach and communicate a decision.

## 2. Major Incident

A suspected exploit threatens player data. Explain how you would coordinate containment, evidence preservation, technical response, and player communications.

## 3. Permissions and Accountability

A staff member requests unrestricted permissions for a specific task. Explain how you would evaluate the request and document the decision.

## 4. Leadership and Continuity

Describe how you would delegate work, support a struggling staff member, and prepare a handover for the next Server Lead.

Results are reviewed and recorded privately under the [Assessment Process](process.md){ data-preview }.
