   - The economy is one of the most important aspects of the server when it comes to interacting with other players. The only source of generating money on the server is by selling diamonds, using `/sell` or by speaking with the diamond trader NPC in spawn. # Module 4 · In-Game Systems

ERRSA MC contains many systems, including several that are custom-built specifically for the server.

This module provides a basic overview of the major **player-facing systems** and how players interact with them.

!!! info "Reference material"
    This module is intended to teach you the basics. For detailed player-facing information, refer players to the ERRSA MC website handbook. For technical information, use the relevant Plugin or Tool documentation.

---

## Player Registration

Player registration is the first major system most players encounter and is one of the most common sources of questions.

The registration process verifies that players are current Embry-Riddle students before granting them normal server access.

!!! tip "Learn the registration process"
    Review the [player onboarding tutorial](https://www.youtube.com/watch?v=nrxG9c11pdo "Click here to watch the tutorial video!") and the [PlayerInitialization plugin](../../plugins/playerinitialization.md#){ data-preview } documentation for more information.

---

## Server Menu

The `/menu` command provides a central location for many of the most commonly used server features.

Players can use it to access things such as:

- Warps.
- Guilds.
- Discord.
- The website.
- The world map.
- Other server features.

---

## Tutorials

The `/tutorial` command sends players to the **Tutorial Dojo**, where NPCs explain the major systems available on the server.

The dojo provides an easy in-game way for players to learn without needing to leave Minecraft.

---

## Teleportation Commands

Common commands include:

| Command | Purpose |
|---|---|
| `/wild` | Travel to a random location in the survival world. |
| `/tpa` | Request to teleport to another player. |
| `/warp` | Open the server's warp system. |
| `/home` | Manage and teleport to personal homes. |

---

## World & Map Navigation

ERRSA MC provides a live map that allows players to view the server world outside of Minecraft.

Players can access it through the website or by using:

```text
/map
```

---

## Server Browser & Worlds

The `/servers` command opens the server browser and allows players to move between the different servers in the network.

The network currently includes:

- Main Survival.
- Creative.
- Events.
- Backup/Dev.

Players can access the Creative server and claim a plot with:

```text
/plot auto
```

---

## Rank Progression

The Rank Progression system rewards players for active playtime on the server.

Players can view their progression with:

```text
/progression
```

Personal playtime can be viewed with:

```text
/playtime
/pt
```

Players can compare their playtime with the rest of the server using:

```text
/playtime leaderboard
/pt top
```

---

## Economy & Shops

The economy provides a way for players to trade items without relying entirely on direct barter.

The primary source of money is selling diamonds.

Players can sell diamonds through `/sell` or by interacting with the Diamond Trader NPC at spawn.

Money can be transferred directly using:

```text
/pay <username> <amount>
```

Players can also create shops by holding an item and interacting with a chest or barrel.

!!! info "Player shops"
Creating a shop costs money, so players will need to earn some money first. Shops allow players to buy and sell items without needing to be online at the same time.

---

## Guilds

Guilds allow players to collaborate and represent themselves with a shared in-game identity.

Players can manage and view guilds through:

```text
/guilds
```

Additional guild information is available through:

```text
/warp guild_hall
```

---

## Tokens

Tokens are rewards obtained through the Rank Progression system.

There are currently three token types:

- **Music Disc Tokens** — Used to request custom music discs.
- **Map Art Tokens** — Used to request custom map art.
- **Head Shop Tokens** — Used to obtain decorative player heads.

Music disc and map art requests go through an approval process.

!!! info "Staff approval"
    Requests appear in the appropriate staff Discord channel and can be reviewed and approved or denied by staff.

---

## VIP

The VIP system is currently a **work in progress**.

When released, VIP will provide a way for players to directly support ERRSA MC financially. Revenue will help cover hosting costs and support events with real prizes.

Planned benefits include:

- A gold VIP tag.
- A custom NPC at spawn.
- Access to progression rewards.
- Additional tokens.
- Other cosmetic or quality-of-life benefits.

!!! warning "Coming soon"
    VIP is not currently available for purchase, and its final features may change before release.
