# Module 5 · Communication & Staff Resources

A successful staff team depends on clear communication, documentation, and collaboration.

ERRSA MC uses several centralized systems to make sure information is available to the people who need it and preserved for future staff teams.

---

## Discord

The ERRSA MC Discord is the primary location for staff communication and collaboration.

Unless a conversation is intentionally private or sensitive, staff discussion should generally happen in Discord.

This provides several benefits:

- Other staff can see questions and answers.
- Important decisions remain accessible.
- Staff can provide input when appropriate.
- Information does not become isolated in private conversations.

!!! tip "Overcommunication is better than undercommunication"
    If you are unsure whether something should be communicated to the staff team, it is generally better to share it than to leave everyone guessing.

---

## Staff Documentation

Documentation is especially important for ERRSA MC because staff membership naturally changes over time as students graduate and move on.

Good documentation allows future staff to:

- Understand how systems work.
- Understand why decisions were made.
- Continue existing projects.
- Avoid repeating previous mistakes.
- Build on the work of previous teams.

The primary source of server documentation is this wiki.

---

### Where Information Is Stored

| Information                            | Primary location                 |
|----------------------------------------|----------------------------------|
| Staff procedures and server reference  | This wiki                        |
| Server files and operational data      | Apex Hosting                     |
| Local server backup                    | Secure local backup              |
| Sensitive player and registration data | ERRSA Microsoft 365 / SharePoint |

A local server backup is downloaded once per year and stored in a secure location.

!!! warning "Protect sensitive information"
    Do not place [private player information]("This typically includes real names, student emails, residence halls, or any other identifying information."), registration data, or other sensitive information in public documentation or general staff channels.

---

## Reporting

SWhile answering questions and being a helpful resource to the community is the primary function of staff members, you may also need to respond to player reports and take administrative action.

All official player reports should be submitted through the designated [Official Report Form](https://forms.fillout.com/t/eRqvr1KnD4us).

Reports are routed directly to the staff channel on Discord for review.

Administrative actions and their associated documentation are handled through the [staff action process](../../documentation/logging-documentation.md){ data-preview } using our custom Discord bot.

!!! info "More detailed moderation training"
    The Moderator learning track contains detailed instructions for reviewing reports, taking action, and documenting disciplinary incidents.

---

## Feedback

Similar to reporting, the [Official Feedback Form](https://forms.fillout.com/t/s2oKYJtMGDus) routes submissions to the staff Discord channel so the team can review and discuss them.

Feedback is also encouraged through other appropriate channels. Not every useful suggestion needs to come through the formal form.

!!! tip "Important note"
    Constructive feedback is valuable even when it does not result in an immediate change.

---

## Communication Expectations

As mentioned previously in [section 1.2](../../documentation/introduction.md#12-expectations){ data-preview } and [section 2.2](../../documentation/staff-roles-responsibilities.md#22-staff-conduct-expectations){ data-preview }, staff should:

- Communicate clearly.
- Provide enough context for others to understand the situation.
- Document important actions and decisions.
- Keep discussions in the appropriate channel.
- Escalate when additional input is needed.

!!! warning "Document important actions!"
    If a report, feedback item, server change, or especially an administrative action occurs, it **must be documented somewhere appropriate**.

As a general rule, the staff Discord channel is a good place to document an issue so the rest of the team has visibility.

The exception is information that is sensitive or private, which should only be shared through the appropriate restricted system.
