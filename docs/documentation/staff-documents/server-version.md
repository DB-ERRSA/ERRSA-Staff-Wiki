# 5. Server versions

## 5.1 Version numbers

Version numbers help staff communicate the scope of a release. The [server changelog](../changelog/server.md#server-changelog){ data-preview } is the source for the latest **documented** release.

| Part | When to increase it |
| --- | --- |
| Major (`X.0.0`) | Full reset or major overhaul. |
| Minor (`0.X.0`) | Significant feature, plugin, or gameplay change. |
| Patch (`0.0.X`) | Small bug fix or configuration adjustment. |

For example, from `1.3.4`, a significant new plugin release might become `1.4.0`; a bug fix might become `1.3.5`. 
## 5.2 Release notes

Update the [server changelog](../changelog/server.md#server-changelog){ data-preview } when a release is approved. The latest entry currently documented there is **1.3.2 (September 9, 2026)**; verify the live server separately before calling that its running version.
