## Luck Perms


### Overview

The server utilizes a plugin called LuckPerms to manage roles, prefixes, and permissions for different groups or users. Server roles are split into 3 tracks, Main, ERRSA, Staff with each track having their own groups

Main – Default, User, VIP

ERRSA – ERRSA, Hall Rep, Legacy, Exec Coord, Exec Board, Advisor

Staff – Mod, Admin, Dev
