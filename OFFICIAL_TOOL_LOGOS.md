# ERRSA Tools: original brand geometry, ERRSA color treatment

- Power Automate uses Microsoft’s full vector SVG from its public GitHub repository. A CSS filter shifts the original blue gradient toward ERRSA teal while preserving its underlying geometry, opacity, and tonal variation.
- Tebex uses the full original Tebex SVG from its public Headless-Template repository as a CSS mask. The silhouette inherits the same theme accent as the other Tools icons. The Tebex source is a **horizontal wordmark**, not an isolated standalone mark.
- These files load from public GitHub raw asset URLs; the SVGs are not copied into this ZIP.
- The color treatment is an ERRSA customization; it is not the companies’ official approved brand color.
