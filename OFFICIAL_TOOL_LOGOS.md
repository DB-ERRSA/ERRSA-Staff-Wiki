# Official tool logos

The Tools overview and detail pages now load official, unmodified SVG brand assets:

- Power Automate: https://github.com/microsoft/powerplatform/blob/master/assets/images/PowerAutomate_scalable.svg
- Tebex: https://github.com/tebexio/Headless-Template/blob/main/assets/icons/tebex.svg

These icons are **externally served from the brands’ own GitHub projects**, not bundled locally. The Tebex asset in its official Headless Template is a horizontal logo rather than the standalone icon mark; the official standalone mark is available from https://www.tebex.io/brand-guidelines if you prefer to swap it later.

Keep brand aspect ratios/colors intact. If external SVGs are unavailable or blocked, the icons may not load; download each official SVG and replace the src paths with local relative paths to avoid this dependency.
